توی این بخش تمام اطلاعات کاربر یا مربی یا فروشنده قرار داره 
برای کاربر به شدت مهمه میتونه اهداف یا چیزایی که توی انبوردینگ انتخاب کرده بود رو ببینه و همینطور برای مربی که میتونه بیاد کدهای معرف که میتونه به شاگرد هاش بده رو ببینه
کامل کردن این بخش از اطلاعات برای فروشنده و مربی کاملا اختیاری هستش ولی برای کاربر اجباری
