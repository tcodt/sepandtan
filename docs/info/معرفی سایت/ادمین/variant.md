این بخش خیلی مهمه و فقط ادمین مجازه که بسازه
با استفاده از این Api میتونی تمام وریانت هارو بگیری و به ادمین نمایش بدی 

variants/attribute-definition

با استفاده از فیچر noDetail که فعال باشه اطلاعاتی ارسال نمیشه و فعال نباشه دسته ها رو هم میاره 

تو میای توی بخش ساخت وریانت 
key انگلیسی 
value فارسی 
ویژگی یا قابلیت محصول رو اینطوری معرفی میکنی مثلا 
key =  size  *** value = سایز
key =  warranty  *** value = گارانتی
key =  ram  *** value = رم
key =  storage  *** value = حافظه


بعدش باید اینارو به دسته های مرتبط به خودشون وصل میکنی و زمانی هم که محصولی رو به یه دسته متصل میکنی این وریانت های مرتبط رو برات میفرستم 
اجباری هم نیستش که هر چی وریانت بود برای محصول حتما پر بشه اطلاعاتش 
و این که فروشنده میتونه یه تخفیف رو برای یه وریانت بزاره و برای بقیه نزاره یا چند مدل تخفیف بزاره برای وریانت هاش از نو product خود سیستم به صورت پیش فرض همیشه ارزون ترین هاشو انتخاب میکنه
